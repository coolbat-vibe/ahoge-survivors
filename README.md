## 🛠️ 项目工程结构与重新构建

```text
ahoge-survivors/
├── ahoge-survivors.html  # 最终生成的 100% 离线单文件可玩成品（中英双语）
├── build.js              # 零依赖单文件打包与语法/离线纯净度校验脚本
├── package.json          # 项目脚本配置
└── src/                  # 模块化源码目录
    ├── template.html     # 界面结构与弹窗布局
    ├── styles.css        # 卡通玩具质感 UI 样式、笔记本紧凑适配与微动效
    ├── data.js           # 中英双语词条 + 英雄、武器、超武、宝物、魔物、首领与商店配置
    ├── spatial.js        # 零 GC 分配 Int32Array 空间哈希网格与几何工具
    ├── audio.js          # WebAudio 动态多轨卡通 BGM 与复音限流打击音效引擎
    ├── sprites.js        # 2x Retina 卡通粗描边厚涂精灵图集与受击白闪离线烘焙器
    ├── effects.js        # 对象池粒子、刀光弧线、震荡波、激光电弧、贴花与漫画跳字
    ├── entities.js       # 波次导演、怪群分离、多阶段首领红圈预警、四大祭坛与经验融合
    ├── weapons.js        # 10 大武器、10 大超武、英雄冲刺特技逻辑
    ├── game.js           # 主循环、分层渲染管线、残血预警、碰撞结算与双模输入控制
    └── ui.js             # 双语实时热切换、升级选卡/封印、开箱演出、小卖部、图鉴与存档
```

如需修改 `src/` 源码后重新生成单文件 `ahoge-survivors.html`，运行：
```bash
node build.js
```
